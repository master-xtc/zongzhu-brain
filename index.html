使用指南 HOW TO USE · Obsidian 方法论驱动的自生长知识库

  

    

      
1 · 知识库是什么

      
一句话：Obsidian 是「看知识库的」，AI 是「操作它的」；知识库本质是一个 Markdown 目录。本页面就是总助大脑的网页化身——左侧栏是文件树，中间是内容区，图谱是关系图谱，本页就是 README。

      
三层架构① 全量档案：data/knowledge.md（人读）+ data/knowledge.json（机读）；② 可视化：本页 2D 铺展图谱与 Three.js 3D 星系；③ 对接通道：HTTP API / MCP / 文件直读。


      
2 · 目录地图（PARA 对照）

      
姜胡说的工作台方法论：项目 / 资产 / 资源 / 归档 + 灵感库 / 技能。总助大脑的每个 Tab 都对应一个用途：

      

        
方法论点位总助大脑对应用途

        
项目（正在做的事）项目主线 / 需求库当前主线全景、习总需求与能力增强清单

        
资产（处理好的知识）能力全景 / 记忆档案七大域能力、已沉淀的记忆与复盘

        
资源（外来参考）知识图谱 / 规则红线全部节点与关联、底层契约与禁忌

        
归档（暂时不用）growth/reviews 复盘库历史任务复盘，查库复用的依据

        
灵感库（待处理）需求库 REQ 清单待办想法、能力增强申请

        
技能（处理模板）提示词库 / skills54 条提示词、可复用技能文档

4 · 自生长工作流

      
参照 Xuan酱的「自生长」四层（原始资料 → 处理资料 → Skill 库 → 输出），总助大脑的闭环是：抓取 → 整理 → 复盘 → 迭代 → 输出。

      
    
        
  1. 抓取：任何对话中出现的有价值内容，立即写入知识库；
    2. 
        
  2. 整理：结构化进五库（规则/能力/项目/需求/记忆）；
    3. 
        
  3. 复盘：任务后写 reviews 固定结构；
    4. 
        
  4. 迭代：每周成长整合 + R30 规则（对话后自动积累）；
    5. 
        
  5. 输出：可视化刷新，可导出文档、PPT、视频。
    6. 
      

      
# 写入一条新知识（自动刷新档案与可视化）
python D:\小说文件\总助大脑\_build\sync_kb.py --type knowledge --title "方法论点" --detail "具体内容"
# 重扫五库（规则/能力/项目/需求/记忆全量重建）
python D:\小说文件\总助大脑\_build\sync_kb.py --rescan

      
金句知识不是用来存的，是用来查自己的——每进一条新知识，都要问：它和我已有的什么相连？能变成什么行动？

8 · Obsidian 直接使用（下载即用 · 图谱与网页完全一致）

      
整个知识库已导出为 Obsidian 仓库（vault）：115 篇笔记 + 136 条双链。在 Obsidian 中打开图谱（Ctrl+G），节点、连线、分类配色与网页版完全一致——因为两者共用同一份图谱数据。

      
下载方法一：直接下载本仓库根目录的 obsidian-vault.zip；方法二：GitHub 仓库 master-xtc/zongzhu-brain → Code → Download ZIP → 解压后取 obsidian-vault 文件夹。

      
1
解压
把 obsidian-vault 文件夹解压到 D 盘任意位置（如 D:\总助大脑-vault）。

      
2
打开
Obsidian →「打开其他仓库」→「打开文件夹作为仓库」→ 选择该文件夹。

      
3
使用
从「00-总览/总助大脑_MOC.md」开始浏览；按笔记内双链跳转，图谱自动呈现完整关联。

      
新 AI 接任与保障① 读：把本页激活指令或 obsidian-vault 路径（或 99-档案/knowledge_全量档案.md）交给新 AI；② 认：让新 AI 先读「总助大脑_MOC.md」与「01-规则」再干活；③ 写：新知识按「提示词库 → 知识库运营」规范回写并同步 GitHub。保障：主库在本地 D 盘、云备份在 GitHub 同仓库、聊天重要结论即时落盘，不依赖任何单个聊天窗口。
