# 总助大脑技能台：一键调用技能生成提示词（v1.5.0）

领域：开发建站 ｜ 来源：20260826 习总需求：技能可视化+一键调用

技能台是总助大脑 v1.5.0 新增功能页：左侧技能可视化清单（搜索+详情），右侧提示词生成器——选技能、填需求、一键生成标准提示词（自动套用技能要点与输出要求）、复制即用；内置 7 种 iOS 容器变形动效实时 CSS 演示（圆点变胶囊/胶囊变卡片/紧凑态展开/圆角过渡/尺寸变形/内容重排/反向收回），每张卡片可播放动效并可一键载入生成器。维护：技能沉淀放 D:\AI员工体系\growth\skills 后跑 sync_kb.py --rescan 或 --type skill；生成器为通用三段式（背景/需求/技能要点+输出要求），新技能自动生效无需改代码；动效数据在 index.tpl.html 的 MORPHS 数组；页面模板注入脚本 _build\patch_skilldeck_v15.py。线上：https://master-xtc.github.io/zongzhu-brain/ 。
