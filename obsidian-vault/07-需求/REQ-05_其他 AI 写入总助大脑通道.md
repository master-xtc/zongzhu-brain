# 其他 AI 写入总助大脑通道

分类：能力增强 ｜ 优先级：中 ｜ 状态：待批准

习总要求所有有价值内容都能写入总助大脑；除总助外，其他 AI（豆包/Hermes/WorkBuddy/Claude 等）也应能通过 MCP 或 HTTP 直接登记需求、记忆与知识点，实现全员共写共享；方案：在 MCP 增加 sync_entry 写工具或开放 /api/sync POST 端点，待习总批准后实施。

验收：任意员工 AI 通过 MCP/HTTP 一条命令登记条目并自动刷新可视化和档案
