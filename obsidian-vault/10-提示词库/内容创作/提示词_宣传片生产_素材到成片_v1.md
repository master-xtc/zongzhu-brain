# 提示词_宣传片生产_素材到成片_v1

## 名称
宣传片生产（素材 → AI 方案 → 分镜 → 成片）

## 用途
输入产品素材（截图/GitHub/README/网页），端到端产出电影感产品宣传片：AI 先检查素材并输出制作方案，再按分镜配方编排镜头，用 Remotion 渲染成片；沉淀"AI 检查素材 → 输出方案"这一高价值环节为可复用提示词。

## 适用场景
- VIBELAB 工作室 / 健身网站 / 贵州旅游站 / 个人品牌作品集的宣传片、功能演示、发布视频
- 习总给素材要求"做一支宣传片"，且希望 AI 先给方案、习总确认后再出片（对应共同创作模式）
- 需要保证图文一一对应、视觉语言从产品自身生长（不另造"宣传片皮肤"）

## 变量位
- {产品素材}：产品截图 / GitHub 仓库 / README / 网页链接 / 录屏（至少一种）
- {成片规格}：默认 1920×1080 @ 30fps、时长约 24-36s、横屏；可改
- {审美规范}：我方默认深空黑 #0A0A0F 底 + 流光金 #C9A96A 点缀；新中式/国潮元素可选
- {模式}：模板（Ink Press 复现）/ 自主自由创作 / 共同创作（默认共同创作，关键节点确认）

## 正文模板
1. 产品检查（只读，不写业务项目代码）：了解产品定位、主要功能、页面视觉、可展示状态、素材风险；不采集敏感数据、不写视频代码
2. 输出制作方案（习总确认用）：
   - 产品定位一句话 + 核心卖点 3-5 条（从真实功能提炼，不编造）
   - 视觉语言：从产品设计系统/截图提取字体、层级、栅格、配色、圆角、材质 tokens；写清背景/表面/正文/强调/状态色
   - 模式判断：模板 / 自主 / 共同，给出推荐与依据
   - 预计成片规格：时长、分辨率、镜头数、节奏骨架（低→中→高能量曲线）
   - 素材风险清单：账号信息/API Key 是否已打码、敏感数据是否虚构或脱敏
3. 方案确认后：分镜（镜头顺序/时长/具体画面/页面状态/字幕/转场/SFX 钉帧表）→ 素材采集（真实页面截图优先，元素切片 + layout 坐标表）→ Remotion 实现（每镜头一个动效，关键信息落定后呼吸位）→ 渲染 → 抽帧自检 → 对照审美准则验收
4. 交付：成片 mp4 + 静帧自检图 + 使用说明

## 变体
- 变体 A（单镜头动效）：只做一个镜头/一种动效（如数字滚动、卡片飞入），输入指定镜头卡名
- 变体 B（模板快速复现）：点名 Ink Press 模板，直接"换产品复现"，最快出片路径
- 变体 C（纯方案咨询）：只做步骤 1-2，输出制作方案供习总裁决，不进入制作

## 验收标准
- 图文一一对应：片中每个画面/镜头有真实素材或明确虚构标注，无占位图、无图文不符
- 视觉语言来自产品自身：字体/配色/材质复用或克制扩展产品 tokens；不套用无关"宣传片皮肤"
- 数据安全：账号信息打码、无 API Key、敏感数据虚构/脱敏后才可入片
- 每镜头一主角：一种动画手法全片只当一次主角，重复即廉价；SFX 节奏卡点（riser→impact→sparkle 句式）
- 交付格式规范，产物落窗口主目录；沉淀复盘与使用记录
