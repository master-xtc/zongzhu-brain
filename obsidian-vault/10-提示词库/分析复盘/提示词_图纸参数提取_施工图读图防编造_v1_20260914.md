# 提示词_图纸参数提取_施工图读图防编造_v1

## 名称
施工图逐张读图参数提取 · 防编造版（豆包 ark vision）

## 用途
- 把一套建筑施工图（PDF 渲染的 PNG，或扫描件）逐张读成结构化「图纸参数提取单」，用于：备赛建模参数速查、题库锚点、工程量参考。
- 核心解决「总助无视觉 + 模型爱编造」两个问题：本提示词用「禁止推断 + 未见即写未见」的强约束，配合多页互证与裁剪精读，把不可靠的读图结果挡在入库之前。

## 适用场景
- 建筑施工图 / 结构图 / 机电图的成套参数提取（16 张以上成套效果最好，可多页互证）
- 备赛类题库扩充（需要把题目答案锚定到具体图号）
- 图纸与模型/代码实现的一致性核对
- 任何"图上数值要落进生产数据"的场景（禁编造红线场景）

## 变量位
- {图片路径}：单张图纸 PNG 绝对路径（建议单张 200dpi 以上，A1 幅面约 2300×1600px 起）
- {页号}：本张页码（如 p03），用于回报中标注来源
- {项目名}：如「某公建」「某住宅」，写进提示词可显著提升模型对图名的判断
- {关注项}：需要重点读的项目（轴网/标高/门窗表/楼梯详图/大样），默认全给
- {图纸总页数}：成套信息，帮助模型不把单张当全部

## 正文模板（全图粗读 · 每张一次调用）

```
你是备赛材料核对员，正在核对【{项目名}】施工图第 {页号} 张（全套共 {总页数} 张）。
只回报图上可见内容，看不清或图上没有的写「未见」，禁止推断编造、禁止用常识补全。
逐项回报：
1. 图名图号与比例；
2. 轴网开间/进深每条轴线间尺寸序列与总尺寸；
3. 层高与关键标高数值；
4. 墙/板/散水/楼梯/栏杆可见厚度尺寸；
5. 门窗编号样式与尺寸规则；
6. 其他可作题的标注（房间名、索引、剖切、材料做法）。
```

## 正文模板（裁剪精读 · 仅对冲突项使用）

```
这是一张建筑图纸的局部裁剪（已放大 {倍数} 倍），取自【{项目名}】的【{部位}】。
只回报图上可见的尺寸数字，看不清的写「未见」，禁止推断。
逐条回报：1. 从{方向}各轴线之间的尺寸数字各是多少；2. 总尺寸数字是多少；3. {针对性问题}。
```

## 正文模板（表格类精读 · 门窗表/明细表专用）

```
只看这张图纸上的「{表名}」，忽略其余内容。逐行列出表中所有行，一行不漏、按原顺序：
每行回报【编号、洞口尺寸(宽×高)、数量、各楼层层名列及其数值、备注/材质类型】。
看不清的字段写「未见」，禁止推断编造。最后回报表头各列名称与总行数。
```

## 变体
- **成套变体（推荐）**：16 张一次成套跑，用多数票裁决单页读误（开间尺寸在 7 页重复出现 → 一页读错可被推翻）。
- **裁剪变体**：用 `_tool_crop.ps1` 按比例区域裁剪 + 2~4x 放大，专治密集小字尺寸带。
- **高分辨率变体**：若源 PDF 还在，直接以 600dpi 重渲染目标页，比裁剪放大更干净（本次未做，因本机无 PDF 渲染库）。
- **汇总变体**：全部读完后让模型做一次「跨页一致性检查」，只回报互相矛盾的项目，输出待核清单。

## 反例规避（务必写进提示词）
- 反例 1：模型把「未见」写成推测值 → 必须显式写「写『未见』，禁止推断编造」。
- 反例 2：模型自行补全表头语义（如把材质列说成尺寸列）→ 逐字段问，不确定即未见。
- 反例 3：模型对同一张图两次给出互斥表格 → **三次互斥即判定该图该区域不可用**，不挑一个像真的入库。
- 反例 4：把不同页的数值混成一页 → 要求每次调用只喂一张图，回报中带页号。

## 验收标准
1. 每张图有独立原始回报文件，可逐字复核；
2. 每个入库数值 ≥2 页互证，或经裁剪精读二次确认；
3. 自洽性校验：分尺寸之和 = 总尺寸（如 6600+2400+6600=15600）；
4. 冲突项必须裁剪精读定案，或列入「待核」且**不入库**；
5. 待核清单与入库数据物理分离（同一文档也不混写）。

## 使用记录
- 2026-09-14：某公建 16 张图纸提取（BIM 备赛小程序「图纸参数提取与题库扩量」窗1 模块A）。
  - 结果：16/16 读回，轴网/标高/楼梯等 18 条参数入库，34 道锚定题入库。
  - 关键收益：多页互证推翻了 2 处单页读误（进深 2500/15700 → 2400/15600；屋面 20.900 → 20.100）。
  - 关键教训：p12 门窗明细表三次读图三套互斥结果 → 判定 200dpi 不可用，整表入待核，**只入库由平面图与详图互证的编号样式**。
  - 配套命令（Key 只注入进程、禁止打印）：
    `$env:ARK_API_KEY=[Environment]::GetEnvironmentVariable('ARK_API_KEY','User')`
    `python "_tool_vision_local.py" --image "{图片路径}" --max-tokens 2800 --timeout 900 --prompt "{正文模板}" --out "{输出md}"`
  - **重要**：调度网关硬编码 `timeout=300`，密集图纸实测单张最慢 544.9s 会必超时；本任务改用 900s 超时本地副本才跑通。建议网关侧统一改 900s。
