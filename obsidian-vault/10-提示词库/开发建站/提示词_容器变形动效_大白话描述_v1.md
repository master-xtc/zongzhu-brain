# 提示词_容器变形动效_大白话描述_v1

## 一、名称
容器变形动效 · 大白话描述提示词（iOS 7 式）

## 二、用途
- 用大白话向 AI 描述 iOS 风格容器变形动效，让 AI 一次生成符合预期的动效代码（CSS / JS / SwiftUI 等）
- 覆盖 7 种最常见容器形态转换：圆点变胶囊 / 胶囊变卡片 / 紧凑态展开 / 圆角过渡 / 尺寸变形 / 内容重排 / 反向收回
- 既可直接投喂 AI 编程工具（Vibe Coding），也可作为给下属 AI 的任务说明书

## 三、适用场景
- 为按钮 / 卡片 / 弹层 / 播放器 / 数据卡片做容器变形动效
- 动效需求描述不清、AI 反复返工改方向时，用五参数法补全描述
- 需要统一团队动效描述规范（对接 WorkBuddy / Claude / Hermes 任务书）

## 四、变量位
| 变量 | 含义 | 示例值 |
|---|---|---|
| 【目标组件】 | 做动效的元素 | 登录按钮 / 音乐卡片 |
| 【动效名称】 | 7 种之一，或自定义 | 圆点变胶囊 |
| 【起点】 | 初始形状 / 大小 / 内容 / 位置 | 一个 44px 圆形图标按钮 |
| 【终点】 | 结束形态 | 胶囊按钮，内含图标和文字 |
| 【方向】 | 水平 / 垂直 / 整体 / 单属性 | 水平展开 |
| 【内容时序】 | 谁先谁后出现 | 先图标后文字 |
| 【结束状态】 | 停留 / 可收回 + 收回顺序 | 停留展开态，点击逆序收回 |
| 【时长缓动】 | 时长与缓动函数 | 300ms 缓入缓出 |
| 【技术要求】 | 技术栈 / 平台 | CSS + 原生 JS，移动端优先 |

## 五、正文模板（大白话版，至少 150 字）
我要给【目标组件】做一个「【动效名称】」动效。
- 起点：【起点】。
- 终点：【终点】。
- 尺寸变化方向：【方向】。
- 内容出现时间：【内容时序】。
- 结束状态：【结束状态】。
- 时长与缓动：【时长缓动】。
- 技术要求：【技术要求】。
请按以上描述实现：① 先给完整可运行代码；② 用大白话解释关键实现点；③ 收回动效严格按展开的逆序处理，节奏一致；④ 优先使用 transform 和 opacity 做动画以保证移动端流畅。

## 六、变体
1. 精简版（给快模型）：把五参数浓缩成一句话：「【目标组件】从【起点】【方向】变成【终点】，【内容时序】，结束时【结束状态】，时长【时长缓动】」
2. 分步版（要中间态）：五参数 + 要求「把动效拆成 3 步：形态变化 / 内容入场 / 最终停留，每步单独标注时间点」
3. 回退版（要收起）：在五参数后追加「再给一个收起动画：先【先收起的内容】，再缩回【中间形态】，最后回到【起点】」
4. SwiftUI 版：技术要求替换为「SwiftUI，用 withAnimation + matchedGeometryEffect 实现平滑形变」
5. 7 种动效独立模板（来自技能《前端_容器变形动效大白话提示词_v1》表格，每种一行大白话示例，直接取用）

## 七、验收标准
- 生成代码能对应上五参数（起点 / 终点 / 方向 / 内容时序 / 结束状态），缺一算不合格
- 中间态可暂停检查；收回为展开逆序；移动端流畅（transform / opacity）
- 无多余装饰、无路径错误、无死链；命名符合规范
