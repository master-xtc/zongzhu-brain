# 提示词 · 建站_叙事滚动页骨架_v1

## 基本信息
- 用途：用 AI 生成"获奖感"品牌叙事单页站点（滚动驱动 + 大字冲击 + 品牌色）
- 适用场景：品牌落地页、作品展示页、文旅导航页、个人主页
- 版本/日期：v1.0 / 2026-08-13
- 来源：Lando Norris（ScrollTrigger×22 滚动叙事，习总最爱）+ Locomotive + Uni-Yi 实测

## 变量位
- {品牌名}：如 黔行 QIANXING
- {品牌色}：记忆色 HEX（如 荧光绿 #D2FF00 / 保时捷蓝 #1A44EA / 暖金 #C9A96A）
- {深底/浅底}：近黑 #0A0A0F 或 纯白
- {章节数}：4-7 个
- {内容板块}：如 环线/美食/打卡/攻略

## 正文模板

请生成一个单页 HTML 站点（零依赖或仅 GSAP ScrollTrigger），规格如下：

1. 视觉：{深底或浅底} + {品牌色}为唯一强调色；全页 ≤ 2 主色 + 1 点缀色。
2. 字体：展示字体气质（粗衬线高对比或窄体几何无衬线），主标题 ≥ 72px、字重 300-900 依冲击度；正文 ≤ 16px 克制。
3. 滚动叙事（核心）：每屏一个章节；标题随滚动做位移/缩放/遮罩（ScrollTrigger）；章节间平滑过渡；滚动触发大色块切换。
4. 布局：一屏一冲击；大留白 + 满版大图交替；导航锚点平滑滚动。
5. 内容：{章节数} 个章节：hero（品牌名+一句定位）→ {内容板块逐章} → footer（CTA/联系）。
6. 图片：每章配真实图片（图文一一对应）；无图片时用品牌色渐变占位并标注"待补图"。
7. 技术：响应式（移动端优先）；滚动无横向溢出；禁用 emoji。

## 变体

1. **运动速度感**：品牌荧光色 + 大字号 + 章节间速度感（滚动越快标题越大/位移越强）。
2. **机构克制感**（IBM/Uni-Yi）：细体 300 字重巨字 + 大量留白 + 单强调色 + 慢滚动。
3. **高端生活方式**（SonDaven）：白金双色 + 等宽字体小标注 + 大图轮播章节。
4. **文旅导航**（黔行场景）：深底 + 暖金点缀 + 环线时间线章节 + 每站图文对应。

## 验收标准
- 移动端 390px 无横向溢出；锚点导航正常；
- 每章图片与内容一一对应，无破图；
- 滚动动效流畅（无卡顿），标题冲击感达标；
- 无 emoji、无花哨装饰、无低质占位残留。
