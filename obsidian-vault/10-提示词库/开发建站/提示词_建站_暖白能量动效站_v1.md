# 提示词_建站_暖白能量动效站_v1

## 名称
暖白能量动效站（个人数据工具穿品牌叙事皮）

## 用途
生成"亮色高级感 + 动漫式能量感动效"的移动端优先静态网站；适用于个人工具站、作品集、品牌叙事站

## 适用场景
- 习总"高级感公式"要求的任何网站（亮色基底 + 高饱和点缀 + 动态交互特效 + 动漫能量感 + 克制）
- 私用工具兼作品展示（如健身指挥台）
- 需要从深色/朴素版升级到亮色动效版

## 变量位
- {色板}：底/主/点缀三色（默认 #FAF7F2 / #1A1A1A / #7CFF5A）
- {站点名}：品牌或产品名
- {功能模块}：数据记录/训练/饮食/图表等
- {动效开关}：桌面全量 / 移动端降级

## 正文模板
亮色暖白底 + 墨黑文字 + 高饱和荧光点缀（1-2 色），全部 CSS 变量；大圆角卡片 + 柔和阴影；动效：Canvas 能量粒子/光晕（桌面）+ Hero 大标题逐字弹性入场 + 速度线 + Lenis 平滑滚动 + 章节滚动叙事（位移/缩放/遮罩）+ 视差 + 数字滚动 + 卡片 3D 倾斜 + 按钮磁吸 + 打卡能量波纹 + 视图转场 + 图表生长动画；移动端降级为轻量；功能/数据层与视觉层解耦；无 emoji、SVG 线性图标、图文一一对应。

## 变体
1. 荧光绿点缀（默认）
2. 电光蓝点缀 #2B4BFF
3. 活力橙点缀 #FF6B35
4. 复古运动（纸白底 + 高饱和红/青）

## 验收标准
- 390px 无横向溢出；桌面滚动流畅（Lenis+粒子性能）
- 数据层（localStorage/导出导入）零改动仍正常
- 控制台 0 错误；无 emoji、无死链、风格统一
- 色板全走 CSS 变量（换肤一键）
