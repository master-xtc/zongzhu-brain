# 提示词_建站_潮流刊炸裂特效站_v1

## 名称
街头潮流刊炸裂特效站（高级感公式·撕裂碎裂级）

## 用途
把"个人数据工具穿品牌叙事皮"的网站升级为街头潮流刊风格 + 动漫式炸裂特效（分屏撕裂/卡片碎裂重组/文字粒子爆破/粒子爆发/冲击波/速度线/光轨/屏幕震动），功能数据层零改动。适用于任何需要"无与伦比的吸引力"的作品集站、接单背书站、私用工具兼展示站。

## 适用场景
- 习总"高级感公式"路线下的炸裂升级：亮色基底 + 高饱和撞色 + 动态交互 + 动漫能量感 + 极致克制
- 现有动效站（如健身指挥台 v3.0）希望从"含蓄动效"升级到"高光时刻炸裂"的版本
- 需要可复用动效引擎资产的新项目（fx.js 可直接抽走复用）

## 变量位
- {色板三元组}：底/主/撞色（默认 #FAF7F2 / #F5B94C / #7C3AED；可换品红/电光蓝）
- {站点名}：品牌名（默认 FIT COMMAND）
- {功能模块}：数据记录/训练/饮食/体态/周报/设置
- {三件套开关}：开屏撕裂 / 成长轨迹 / 战绩海报（可单开）
- {游戏化开关}：COMBO 连击 / PERFECT 判定 / 能量槽

## 正文模板（完整版）
**角色定位**：品牌叙事设计师 + 高级前端动效工程师，精通 GSAP 弹性缓动（overshoot）、Canvas 粒子系统（含逐像素取样碎裂重组）、clip-path 撕裂转场、冲击波/速度线/辉光等动漫式特效语言。
**目标**：在现有功能完整站点上完成——①街头潮流刊风格整体切换（标题 900 字重斜切叠压、票根/贴纸/收据模块语言、章节斜切标签）；②独立 Canvas 特效引擎 `fx.js`（粒子池上限 150、DPR 上限 2、rAF 节流）；③炸裂特效四记重拳：开场分屏撕裂（双层 clip-path 斜切色块滑开 + 大标题砸落 + 速度线 + 震动）、数据卡碎裂重组（碎块飞散→GSAP 弹性聚合 + 本体 blur 抖动复位）、章节标题文字粒子爆破（Canvas 取样文字→粒子飞散→重组）、成就解锁"天地异变"（闪白 + 粒子风暴收束 + 冲击波）；④展示力三件套（开屏叙事 ≤3s 可跳过仅首访 / 成长轨迹时间轴双曲线 + 体型示意联动 / 周报战绩海报导出 PNG）；⑤游戏化爽感（连续打卡 COMBO ×N、周目标 PERFECT 判定、蛋白质能量槽）。数据层（localStorage 键、store/charts 逻辑）零改动。
**受众**：习总本人（私用爽感）+ 作品展示访客（接单背书）；隐私红线——任何展示面不得出现真实体重/腰围数值，战绩卡只呈现统计与相对变化。
**风格与语气**：亮色基底暖米白 `#FAF7F2` + 墨黑主文字 + 蜂蜜暖黄主点缀 + 电光紫撞色（限 2 记忆色）；无 emoji、SVG 线性图标、图文一一对应；大留白 + 大圆角 + 柔和阴影。
**结构要求**：动效节奏铁律——炸裂只在高光点（开屏/数据卡首现/章节标题/成就解锁/战绩卡生成/视图切换），平时安静；碎裂重组与文字爆破每视图最多 1 次防疲劳；桌面全量、移动端降级（关闭粒子取样/光轨，保留辉光/冲击波/弹性）；尊重 prefers-reduced-motion。
**示例**：动漫 OP"蓄力→爆发→定格"节奏 + Nike/Supreme 联名海报排版；落地案例见 `D:\健身教练\网站\assets\js\fx.js` 与 `main.css` v4.2 覆盖段。
**反例规避**：禁止 emoji；禁止深色底；禁止特效常驻堆满（防廉价与视觉疲劳）；禁止破坏数据键与导出导入；禁止移动端粒子取样（性能红线）；禁止新增第三方依赖（碎裂重组自写 Canvas 取样，GSAP/Lenis/ECharts 复用已有 CDN）；禁止战绩卡出现具体体重/腰围。
**验收标准**：390px 无横向溢出；开屏 ≤3s 可跳过；移动端不卡顿；数据层零改动；控制台 0 错误；离线可用（SW 版本号升级并注册 fx.js）；新视觉全走 CSS 变量（换肤一键）；图文一一对应；视觉终验由视觉下属/习总目视确认（总助不自欺）。
**变量位说明**：撞色第二色影响斜切标签/贴纸角标/COMBO/判定字/战绩卡紫块；三件套可独立开关（每件约 30-45 分钟）；游戏化开关独立（约 20 分钟）。
