# 提示词_微信小程序数据文件排查与验收_开发建站_v1_20260826

## 用途
微信小程序（含自定义 tabBar/多页）开发中排查「编译报错 + 数据文件运行时读取失败」并做 P3 阶段全流程验收。

## 适用场景
- IDE 编译报错（getRootFactory 类环境错误 / WXML 语法错误）排查
- 小程序 data/*.json 运行时 readFileSync permission denied / 空数据排查
- P3 阶段互动特效 + 页面完善后的自动化+静态双通道验收

## 关键结论（复用要点）
1. 编译错误分层：IDE 内部环境（栈在 app.asar，清缓存/重启）→ 源码错误（WXML 字面转义、标签）→ 运行时数据（permission denied 多为代码包未打包）。
2. data/*.json 动态读取模块必须把全部文件名写入 ALL_NAMES 预载清单；关闭 project.private.config.json 的 ignoreDevUnusedFiles 或保证静态引用可见。
3. 验收双通道：
   - 自动化（miniprogram-automator）：端口 9420，带 withRetry；覆盖页面可达、业务链路（答题→进度→清空→归零）、隐私/关于页、运行时零报错。
   - 静态（Node 全量扫描）：9 类特效定义与调用点、深色残留、emoji（区分彩色 emoji 与 ✓✕ 排版符号）、按压反馈 100%、超宽固定宽度。
4. automator 兼容抖动：navigateBack/currentPage 偶发 timeout，脚本重试兜底；页面内 setTimeout 节奏（ADVANCE_MS）须小于轮询间隔。

## 变量位
- 项目路径、AppID、IDE CLI 路径、automator 端口、数据文件清单、特效类清单。

## 验收标准
- 编译零报错；自动化与静态双通道全绿；关键业务链路（数据写入→读取→清空）闭环验证。
