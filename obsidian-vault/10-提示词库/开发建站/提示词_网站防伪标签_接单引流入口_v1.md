## 八字段
1. **名称**：提示词_网站防伪标签_接单引流入口_v1
2. **用途**：给任何交付的网站/作品加一个"防伪标签"：右下角胶囊按钮，点击向下展开成卡片，显示业务微信号 xtc20you 并提供复制；访客可一键复制加微信联系开发
3. **适用场景**：新网站收尾、已有站点补装（健身指挥台、BIM 站、客户单、作品集）；打开新会话直接调用
4. **变量位**：
   - {SITE_DIR}：目标网站本地根目录
   - {POS}：放置位置（默认 corner 右下角固定；footer=页脚行简易版）
   - {PILL_TITLE}：胶囊标题（默认：找我开发）
   - 已定稿：业务微信号 xtc20you（对外业务号，可对外展示，非隐私）
5. **正文模板**（新会话开场直接粘贴，超百字、要素齐全，已填微信号与交互规格）：

你是 VIBE LAB 娱乐视觉工作室的技术执行，任务：为目标网站加一个"胶囊变卡片"防伪标签。起点：右下角固定胶囊按钮（圆角胶囊、细边框、hover 金色，内含微信 SVG 线性小图标 + 标题"找我开发"）；点击后向下展开成卡片（方向：向下），卡片顶部保留图标与标题，正文与复制按钮逐步出现——出现顺序：微信号正文（文案：微信 xtc20you）先出现，之后"复制"按钮再出现；动效时长 380ms、缓入缓出（ease-in-out），用 CSS 过渡实现（transform/opacity 过渡，不用 JS 动画库）；结束态为停留卡片态，可逆序收回（再点或点外部收回）。交互：点击"复制"或微信号文字，将 xtc20you 写入剪贴板并弹轻提示 toast（文案：已复制：xtc20you），复制失败给手动长按选中提示。禁止海报、开屏弹窗、二维码大图、emoji、多余文案与花哨装饰。样式与站点原生风格统一，卡片字号 12-14px 低调不喧宾夺主，移动端 360/390/430 三视口不溢出、按钮可点、展开不遮挡底部关键内容（必要时卡片向上展开或限制高度）。隐私红线：只显示业务微信号 xtc20you，绝不出现习总真实姓名、电话、邮箱等隐私。交付前本地预览验证：展开/收回动画正确、复制真实生效、toast 正确，桌面与移动视口各测一次；改动前备份到站点备份目录，完成后按 类别_对象_用途_时间 落盘改动记录。验收标准：胶囊可见、点开展开顺序正确（正文先于按钮）、380ms 缓动、可逆收回、复制真实生效、无 emoji 无海报无隐私外泄、三视口 PASS。

6. **变体**：
   - v1b 胶囊展开卡（推荐，默认）：右下角胶囊 → 向下展开卡片（交互规格见正文模板）

## 反例规避
- 不做海报、开屏弹窗、二维码大图、插画与多余文案
- 不放习总真实姓名、手机号、邮箱，只放业务微信号 xtc20you
- 不用 emoji、花哨动效；图标用 SVG 线性
- 动效必须 CSS 过渡实现且顺序正确：正文先出现、复制按钮后出现，禁止同时弹出
- 复制功能必须真实可用，不许只做样式不做事件
- API Key、部署令牌一律不进提示词与代码
