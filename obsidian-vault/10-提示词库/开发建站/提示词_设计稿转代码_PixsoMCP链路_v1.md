# 提示词 · 设计稿转代码 Pixso MCP 链路

## 基本信息
- 用途：建站/接单时，把"设计稿 → 高保真前端代码"链路跑通（设计 AI 出稿 + MCP 读结构化数据转码）
- 适用场景：独立开发被 UI 样式拖进度；客户要求"设计稿先行确认"再开发；个人产品想做出专业级 UI
- 版本/日期：v1.0 / 2026-08-14

## 变量位（使用时替换）
- {设计工具}：Pixso（默认）/ Figma / 其他支持 MCP 的设计工具
- {目标App/页面}：要复刻或新建的界面（如：生存确认打卡 App、后台管理看板、健康管理移动端）
- {风格要求}：设计风格提示词（如：新野兽主义风格 / 暖白能量动效 / 国潮新中式）
- {编程AI}：Claude Code（默认）/ Cursor / VS Code / Windsurf

## 正文模板
1. 出稿：打开 {设计工具}，用 Pixso AI 生成 {目标App/页面} 设计稿，提示词示例：
   "复刻/新建一个 {目标App/页面}，我想要 {风格要求}。包含完整图层：圆角、间距、颜色变量、组件状态。"
2. 启用 MCP：{设计工具} 客户端（≥2.2.0）文件菜单开启 Pixso MCP，确认本地服务器 http://localhost:3667/mcp 已启动
3. 挂载：在 {编程AI} 终端执行 `claude mcp add --transport http pixso-desktop http://127.0.0.1:3667/mcp`，确认写入本地配置
4. 转码：复制设计稿容器链接，丢给 {编程AI}，只说一句"生成HTML代码"
5. 验收：核对圆角、间距、颜色变量是否与设计稿一致；Web 后台与移动端各验一版

## 变体
1. 变体 A（无设计工具）：让 Claude 直接按"高级感公式"规范写代码（亮色基底+高饱和撞色+动效），跳过设计稿
2. 变体 B（素材白嫖）：从 {设计工具} 社区复制现成设计稿/组件库，再走 MCP 转码，省去出稿步骤
3. 变体 C（免费替代）：Stitch 等免费工具对比实测后再定链路

## 验收标准
- 生成界面还原度高：圆角、间距、颜色变量对得上设计稿
- 全程不靠"截图+看图猜"，走结构化数据通道
- 挂载命令成功并有端口监听确认（3667）
- 产出落窗口主目录；提示词使用记录更新
