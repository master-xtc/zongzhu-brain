# 提示词 · 小说 A 类情境切片分镜脚本生成（通用）

> 版本：v1 · 2026-11-02
> 分类：短视频 / 小说推广
> 适用：番茄、起点等网文作品的抖音竖版引流视频

---

## 一、名称

提示词_短视频_小说A类情境切片分镜脚本生成_通用_v1

## 二、用途

把任意一章小说正文，转换成**可直接开工**的抖音竖版情境切片分镜脚本（30-45 秒）。
输出物是分镜表，不是文案，不是小说缩写。

## 三、适用场景

- 网文作者给连载作品做抖音引流；
- 已有正文、需要批量出短视频脚本；
- 需要保证"同一条视频里人物不漂移、节奏不拖沓"。

**不适用**：口播类、书荒推荐类、多章节混剪（那些走别的模板）。

## 四、变量位

| 变量 | 说明 | 是否必填 |
|---|---|---|
| `{章节正文}` | 要改编的单章全文 | 必填 |
| `{人物视觉卡英文块}` | 出场人物的固定英文描述块 | 必填 |
| `{风格锚}` `{负面锚}` | 全片统一的画风与排除项 | 必填 |
| `{平台书名}` | 如「番茄小说《余额之眼》」 | 必填 |
| `{时长}` | 默认 38 秒，可 30-45 | 选填 |
| `{结尾变体}` | A 悬念 / B 提问 / C 存量 | 选填 |

## 五、正文模板

```
你是短视频分镜师。你的任务是把下面这章小说正文，转成一条 30-45 秒的竖版情境切片分镜脚本。
你只做视觉化，不做二次创作：台词只能从正文原句里摘，不许自己写。

【输入】
章节正文：{章节正文}
人物视觉卡：{人物视觉卡英文块}
风格锚：{风格锚}
负面锚：{负面锚}
平台书名：{平台书名}

【第一步 · 选段判定】
先判断这一章是否同时满足三条：
1) 一句话能讲清冲突（说给没看过书的人，5 秒内能明白谁逼谁）；
2) 有一个可视觉化的奇观（数字/光/雨/镜面/逆光，必须能画出来）；
3) 有一个不解释的悬念（观众会问"为什么"，不是"然后呢"）。
若任一不满足，直接说明不满足的是哪一条，并给出"换章"建议，不要硬改。
若涉及未成年人受害、疾病细节、真实机构、地域纠纷，直接判为不可用。

【第二步 · 四拍切分】
- 第一拍 钩子 0-3 秒：只给"事"，不给"人脸"。静音也必须看得懂有事发生。
- 第二拍 冲突 3-16 秒：压迫感拉满，台词总数不超过 3 句。
- 第三拍 奇观 16-30 秒：全片只允许一个视觉奇观，且必须是"浮在空气里"的效果，不是贴图。
- 第四拍 落钩 30-38 秒：一句反转 + 一行书名。不解释设定，不喊"点击下方"。

【第三步 · 镜头分配】
单镜 2-4 秒，全片 8-11 镜，每 6-8 秒必须有一次画面变化（切镜/推近/光变/字幕弹出）。

【第四步 · 输出分镜表】
| 镜号 | 时间码 | 景别·运镜 | 画面提示词 | 字幕 | 旁白/台词 | 音效 |

填写规则：
- 画面提示词只写"这一镜多出来的东西"。人物外观一律写「粘贴视觉卡 §X 原文」，禁止重写外观（重写必然漂移）。
- 字幕 ≤14 字、最多两行、必须自带信息，不许与旁白逐字重复。
- 旁白/台词必须从正文原句摘录；没有原句的地方留空，让画面说话。
- 音效只写三类：低频撞击、环境音、静音留白。禁止写配乐情绪词。

【第五步 · 自检】
输出后逐条自查并列出结论：
1) 静音看一遍，能否看懂发生了什么；
2) 每个出场人物是否都标了视觉卡出处；
3) 旁白按 4.5 字/秒 折算，是否超时长；
4) 奇观镜是否只有一个视觉元素；
5) 最后一帧是否留 0.5 秒黑场。
```

## 六、变体

| 变体 | 改动 | 适用 |
|---|---|---|
| A 悬念向 | 结尾字幕改为"他看不见自己的数字" | 测"为什么"型观众 |
| B 提问向 | 结尾改为提问句，引导评论区 | 测互动率 |
| C 存量向 | 结尾加"全书已写到第 X 章" | 测追更意愿 |
| C 类加长版 | 时长拉到 60-75 秒，允许两段奇观 | 卷末大反转专用 |

## 七、验收标准

- 静音可懂；
- 人物与视觉卡零偏差（外套颜色、标志物、疤/断指等）；
- 台词 100% 出自正文；
- 时长误差 ≤2 秒；
- 无解释设定、无硬导流、无二维码。

## 九、踩坑记录

1. **人物块不能改写**：哪怕只把 "dark olive bomber jacket" 改成 "olive jacket"，出来的就是另一个人。
2. **旁白不要写满**：AI 配音按 4.5 字/秒算，写满 38 秒的旁白会让画面没气口，观众憋得慌。
3. **奇观镜最容易做废**：一旦在数字旁边再加雨、再加慢镜、再加人物特写，观众的注意力就散了。一个就够。
