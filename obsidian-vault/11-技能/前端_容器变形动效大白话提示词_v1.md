# 技能：前端_容器变形动效大白话提示词_v1

## 技能名
容器变形动效 · 大白话提示词法（iOS 7 式）

## 用途
- 用大白话向 AI 描述 iOS 风格容器变形动效，让 AI 一次生成符合预期的动效代码（CSS / JS / SwiftUI 等均可）
- 覆盖 7 种最常见的容器形态转换（圆点→胶囊→卡片→收起），避免动效说不清、AI 反复返工
- 既可用于 Vibe Coding 直接生成，也可作为给下属（WorkBuddy / Claude）的任务说明书

## 触发场景
- 需要为按钮 / 卡片 / 弹层 / 播放器做容器变形动效
- 想把 UI 交互做高级，但说不清动效细节
- 动效被 AI 改错方向（展开了不该展开的、收不回去），用五参数法补全描述重试

## 核心方法论：五参数沟通法（视频总结，必用）
与 AI 描述容器变形动效，必须说清 5 个参数，缺一个 AI 就靠猜：
1. 起点：元素初始状态（形状 / 大小 / 内容 / 位置）
2. 终点：元素结束状态（展开成什么 / 停在什么形态）
3. 尺寸变化方向：水平展开 / 垂直展开 / 整体缩放 / 只变单一属性
4. 内容出现时间：内容谁先谁后出现（图标→文字→详情→按钮）
5. 结束状态：停留展开态，还是可收回；收回时谁先消失（一般逆序）

## 7 种动效逐项拆解（含大白话描述示例）
| # | 名称 | 动作要点 | 大白话示例 |
|---|---|---|---|
| 1 | Circle to Pill 圆点变胶囊 | 点击后圆点水平展开成胶囊，图标和文字依次出现 | 一个圆形图标按钮，点击后水平展开成胶囊，先弹出图标，再滑出文字，最后停在胶囊态 |
| 2 | Pill to Card 胶囊变卡片 | 胶囊向下展开成卡片，保留图标和标题，逐步露出详情与按钮 | 胶囊点击后向下展开成卡片，图标和标题留在顶部不动，卡片内部依次出现正文和按钮 |
| 3 | Compact to Expanded 紧凑态展开 | 保持身份不变，扩展可操作区域，封面 / 进度 / 快捷操作重新排位 | 小卡片展开成完整卡片，封面放大当背景，进度条挪到中间，快捷操作按钮排到右侧 |
| 4 | Corner Radius 圆角过渡 | 单独改变圆角，从全圆逐步收紧为卡片圆角，边框 / 底色 / 结果状态同步稳定 | 容器圆角从 50%（全圆）过渡到 12px（卡片），同时边框和底色平滑过渡，不要跳变 |
| 5 | Size Morph 尺寸变形 | 容器按明确方向改变宽高，保持比例和锚点，突出主要数值 | 卡片宽度从 100px 拉伸到 320px，高度不变，锚点固定在左上角，数值放大突出显示 |
| 6 | Content Reflow 内容重排 | 宽度变化时，文字和按钮重新排布，保持阅读顺序 | 容器变宽后，一行放不下的文字自动重排成两行，按钮从图标态变成带文字的完整按钮，阅读顺序从左到右 |
| 7 | Reverse Collapse 反向收回 | 先收起次要按钮和正文，再缩短卡片和胶囊，最后回到圆点 | 收起时顺序反过来：先隐藏按钮和正文，再把卡片缩回胶囊，最后回到圆点 |

## 通用提示词模板（大白话版）
我要给【目标组件】做一个「【动效名称】」动效。
- 起点：【起点状态】
- 终点：【终点状态】
- 尺寸变化方向：【水平 / 垂直 / 整体 / 单属性】
- 内容出现时间：【谁先谁后】
- 结束状态：【停留 / 可收回，收回顺序】
- 时长与缓动：【如 300ms，缓入缓出】
- 技术要求：【如 CSS + 原生 JS、SwiftUI、移动端优先】
请按以上描述实现，先给完整可运行代码，再解释关键实现点；收回动效按展开的逆序处理。

## 反例规避（视频强调的坑）
- 只写“做个动画效果”——没给起点 / 终点，AI 只能乱猜
- 只说“圆角变一下”——没说从多少变到多少、边框底色是否同步
- 展开和收回不写顺序——收回必须是从终点逆序回起点
- 不写内容时序——图标 / 文字 / 按钮同时出现会显得生硬

## 验收标准
- 生成代码中能明确找到起点、终点、尺寸变化方向、内容出现时间、结束状态五要素
- 动画中间态可暂停检查（transition 或 keyframes 可调）
- 收回动画为展开的逆序，节奏一致
- 移动端不卡顿（优先 transform + opacity，不用 layout 属性做动画）
