# 前端技能：本地抠图渐进增强与贴板 Canvas

## 技能名

前端_本地抠图渐进增强与贴板Canvas

## 触发场景

- 静态网站/小程序需要“拍照抠图 + 贴纸摆盘 + 分享卡”。
- 隐私要求图片不上传服务器，需在浏览器本机处理。
- 移动端优先，需要拖动/缩放/旋转与分享图导出。

## 步骤

1. 存储层沿用现有 localStorage，新增独立版本键（如 `fc_foodlog_v1`），导出时合并新键并升级 version。
2. 贴纸用内联 SVG，不依赖外部素材；贴板容器用相对坐标 + 百分比存储 `x/y/scale/rotation`。
3. 图片先压缩到小尺寸（如 512px），再动态 import 抠图库。
4. 抠图调用包 Promise + 90 秒超时；失败或超时统一回落贴纸库并 toast 说明。
5. 分享卡用离屏 Canvas 固定尺寸（如 1080x1350）绘制，`toBlob` 优先 Web Share，不支持则下载。
6. 事件绑定用父容器委托，避免 `innerHTML` 重建后丢失监听。

## 验收标准

- `node --check` 通过，浏览器控制台 0 错误。
- 抠图成功时生成 PNG 并加入贴板；失败时回落贴纸库不中断。
- 拖动/缩放/旋转/删除/保存均写回 localStorage，刷新后保留。
- 导出包含新键且 version 正确；清空可移除新键。
- 手机视口无横向溢出，关键按钮触控尺寸 >=40px。

## 适用模型/环境

- 纯前端静态站 + Netlify Functions；本地 `localStorage`。
- 抠图库：`@imgly/background-removal@1.7.0` CDN 动态 import。
