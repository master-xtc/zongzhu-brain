# 技能：商业分析_赛道筛选与裂变获客模型_v1

## 技能名
赛道筛选与裂变获客模型

## 触发场景
- 习总或客户询问「做什么赛道 / 做什么小程序 / 怎么裂变获客」
- 接单立项前的赛道可行性判断
- 私域 / 内容账号冷启动前的定位选择

## 核心认知
「量大但少人注意」的需求本质是认知差：用户想要但说不出专业词。
万能产品形态 = 词典 + 清单 + 测试 + 生成器（四件套）。

## 步骤
1. 自查能力 + 成本三问（成本/产出/必要性），低成本有必要直接干
2. 查库：团队共享记忆 / 提示词库 / growth 沉淀，先复用不重写
3. 用七维评分表给候选赛道打分（人群基数/痛点频率/认知差/低竞争/裂变钩子/变现距离/合规），28+ 可做，24-27 补短板，<24 放弃
4. 过三个一票否决（医疗法律金融只能科普 / 一次性无传播 / 变现超 3 个月）
5. 三句话验证法：需求一句话 + 钩子一句话 + 变现一句话
6. 套裂变钩子七式选主钩子（测试打分/清单收藏/生成器/对比/日历提醒/资料包/组队拼团）
7. 出 7 天 MVP 验证清单：1 页面 + 1 钩子 + 1 变现通道 + 0 预算自然分发，验收=私域+100 人或 1 次付费咨询
8. 落盘主目录 + 回填 reviews/skills

## 验收标准
- 交付含：结论先行 + 评分表 + 三句话验证 + MVP 成本估算 + 风险提示
- 文件命名符合规范，落在窗口主目录
- 交付汇报附成本与必要性结论 + 能力自查结论

## 适用模型 / 工具
- 总助 Codex 直接产出（纯分析/写作链路）
- 后续开发阶段：VibeCoding / 小程序三端打包技能；视觉由豆包/下属
