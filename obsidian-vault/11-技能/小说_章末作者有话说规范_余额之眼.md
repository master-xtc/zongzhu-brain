# 技能：小说_章末作者有话说规范（余额之眼）

## 技能名
小说章末“作者有话说”分级写法（番茄主更 / 起点备用）

## 触发场景
每章正文完成、准备落盘时；卷末、大反转、上架、请假、改更新时间等节点尤其适用。

## 核心判断
作者有话说不是正文，不占 5000 字额度；它只服务追读、互动、必要通知三件事。**宁缺毋滥**，常规章可以没有。

## 步骤
1. **判档位**：必加（上架/首秀/求收藏/请假/改时间/卷末）→ 建议加（每5章小高潮、第30章大反转）→ 不加（常规日更、过渡、伏笔章）。
2. **选模板**：悬念型（一句回扣+下章预告）、情绪型（一句情绪+下章动作）、互动型（一个具体问题）。三选一，不混用。
3. **控长度**：必加 ≤80 字，建议加 ≤50 字，不加档最多一句 ≤20 字。
4. **平台适配**：番茄少求票、重催更与完读率；起点可求推荐票/月票，但仍控制在一屏内。
5. **落盘**：正文后用 `---` 分隔，与正文同一 .md 文件；随后执行自动打开。
6. **汇报标注**：`作者有话说：无 / 一句预告 / 必加`；卷末与大反转必须提示“已加互动位”。

## 四条禁忌
1. 不剧透后文、不提前解释设定与伏笔。
2. 不写长篇创作感想、不写“感谢大家支持”模板话。
3. 不每章重复同一句求票/求收藏。
4. 不用作者有话说补正文漏洞，正文问题回正文修。

## 验收标准
- 常规章：0-1 行，不打断阅读。
- 节点章：2-4 行内说清事，且只有一次引导。
- 全文无剧透、无设定解释、无模板套话。
- 不占正文 5000 字计数。

## 适用模型
Codex / WorkBuddy 写作岗；番茄主更优先，起点可放宽求票。

## 踩坑记录
- 每章都写“求收藏”会显得机械，反而拉低追读。
- 用作者有话说解释上一章没写清的逻辑，会让读者觉得作者在打补丁。
- 长篇创作感想在番茄几乎无人读，还占掉章末黄金互动位。
