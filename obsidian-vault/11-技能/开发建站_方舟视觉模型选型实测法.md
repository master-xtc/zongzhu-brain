# 技能_开发建站_方舟视觉模型选型实测法

## 技能名
方舟（火山引擎 ARK）视觉模型选型实测法

## 触发场景
- 网站/工具需要"拍照→AI 识别"（算热量、体态评估、OCR、图像理解），需选豆包视觉模型
- 已有接入点响应慢（>30s）或超平台函数上限，需换模型
- 不确定账号下有哪些可用模型、该选哪个

## 步骤
1. **列模型（不猜）**：调用 `GET https://ark.cn-beijing.volces.com/api/v3/models`，Header `Authorization: Bearer $ARK_API_KEY`，取 `data[].id` 全量清单
2. **筛视觉理解**：从清单筛 `vision` 关键词，排除三类——`embedding-vision`（向量嵌入，不能对话）、`seedance`（视频生成）、`seedream`（图像生成）；保留 `vision-pro / vision-lite / seed-*-vision`
3. **查硬约束**：平台函数上限（Netlify 同步 60s 固定 / 背景 15min；Vercel 10s 等）写入约束
4. **实测直调**（可选）：先试模型 ID 直调 chat/completions，404 则确认必须建接入点（本账号实测 404）
5. **建接入点对比**：控制台创建 2 个接入点（Lite + Pro 各一，按量付费无月费），记录 ep- ID
6. **同图计时**：同一张测试图（640px 食物图 + 人体图各 1），同一 prompt，逐接入点计时 ≥2 次；验收：< 60s 达标，理想 < 30s；记录全部数据
7. **选定落盘**：选最快达标者；另者留作备用/降级；实测数据写入项目分析文档 + growth\reviews 复盘

## 验收标准
- 模型清单来自 API 实测，无凭记忆猜测的 ID
- 每次选型决策附 ≥2 次实测耗时数据
- 测试图用后即删；Key 不写文档

## 适用模型
总助 Codex / 任意具备网络与脚本能力的 AI 员工
