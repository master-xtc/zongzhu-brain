# 技能：静态知识库加密与只读发布

## 技能名

开发建站_静态知识库加密与只读发布

## 触发场景

- 需要把本地知识库、内部文档站或可视化资料分享给他人。
- 需要防止未授权查看，同时不希望对方修改源文件。
- GitHub Pages、Netlify、Cloudflare Pages 等静态托管需要增加访问门槛。
- 需要区分完整版、共享版和只读发布版本。

## 核心步骤

1. 先分类数据：完整版、共享版、公开静态资源，禁止三者在同一发布包中混放。
2. 在源数据对象上执行脱敏，不在序列化后的 JSON/HTML 字符串上做事后路径替换。
3. 共享版隐藏私密记忆、敏感复盘、账号、密钥、邮箱、手机号、路径和本地接口。
4. 对脱敏后的 JSON 做语法解析校验，确认结构可被浏览器读取。
5. 生成共享版明文预览，但预览目录明确标注“勿上传”。
6. 使用 AES-256-GCM 加密首页内容，PBKDF2-SHA256 派生密钥，建议迭代次数不低于 300000。
7. 密码只放在独立密钥文件或密码管理器中，不写入页面、不写入总结、不写入仓库。
8. 新仓库只放密文页面和公开静态资源，不添加外部协作者写权限。
9. 主分支禁止删除和强制推送；需要协作时使用 Fork 或 Pull Request。
10. 发布后实测错误密码、正确密码、页面功能和浏览器控制台。

## 验收标准

- 未解锁页面源码不含知识库明文关键字段。
- 隐私扫描全部通过，无邮箱、手机号、证件号、内部路径、本地地址、密钥样式和真实姓名上下文。
- 错误密码被拒绝。
- 正确密码可解锁。
- 浏览器控制台无错误。
- 仓库无外部写权限，分支删除和强制推送已关闭。
- 总结文件中不出现密码正文。

## 适用模型

- Codex 总助负责统筹、构建、发布与验收。
- 需要视觉核对时派具备视觉能力的下属检查页面。
- 部署平台授权动作由总助执行，涉及账号访问控制时按习总裁决。

## 注意事项与踩坑

- 前端密码层只防未授权查看，不能阻止已授权者复制内容。
- 公开仓库中的密文可被下载，安全性取决于密码强度和加密参数。
- 不要在序列化后的 HTML 上做路径替换，可能破坏 JSON 转义；本次曾因此产生浏览器 JSON 解析错误。
- GitHub Pages 没有原生账号级访问控制，需要可撤销权限时应使用 Cloudflare Access。
- 旧公开完整版地址必须单独处理，否则新增密码页无法消除历史泄露风险。


## 最终版与过程清理补充（v3.13）

- 发布完成后只保留最终部署包、正式更新脚本、必要源数据和最终总结。
- 共享版生成器产生的完整版副本、共享脱敏副本、明文预览、独立报告目录和中间页面，在线上验收通过后应删除。
- 推荐提供一键同步脚本，固定执行“重建→加密→提交→推送→等待 Pages 构建→清理过程目录”。
- 清理函数必须先解析绝对路径并校验目标仍位于指定构建根目录内，再执行递归删除。
- 若推送失败或 Pages 构建失败，不清理过程文件，保留现场供排障。
