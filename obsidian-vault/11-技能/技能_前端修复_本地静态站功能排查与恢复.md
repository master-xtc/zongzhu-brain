# 技能_前端修复_本地静态站功能排查与恢复

> 沉淀日期：2026-09-10｜来源：CET4 四级网站修复任务

## 技能名
本地静态站（单文件 HTML + script.js）功能失效的快速排查与恢复

## 触发场景
- 用户反馈"某功能不能用了 / 倒计时不动 / 点击没反应"，且站点是本地 file:// 打开的单页或多页静态站。
- 页面渲染正常但个别模块报错，或整页交互突然失效。

## 步骤
1. **实测复现**：Chrome DevTools MCP 打开 file:// 页面，`list_console_messages` 拿报错，`evaluate_script` 读关键 DOM（倒计时数值、容器子节点数），拿到堆栈与行号。
2. **静态比对（关键提速步）**：
   - JS `getElementById('x')` 的 id 集合 vs HTML id 集合，差集即潜在 null 断点（注意区分"运行时动态创建"的元素，误报需人工排除）。
   - 函数重名检查：`rg -o '^function \w+' | sort | uniq -d`，同名后者覆盖前者是"某页突然报 null"的高频根因。
3. **修复**：重命名冲突函数（含调用处）；为"清空 innerHTML"的页面加模板缓存 + 恢复函数；把硬编码日期抽成可配置常量（默认值填未来日期，页面可改，存 localStorage）。注意 const TDZ：配置块必须定义在使用它的对象之前。
4. **校验**：`node --check script.js` 语法；再回浏览器 reload（ignoreCache）复测。
5. **交互实测**：用 `evaluate_script` 串起完整闭环（如考试：开考→答题→退出→再考→交卷→看解析→返回），并 stub window.alert/confirm/prompt 防止弹窗阻塞。
6. **数据保护**：改 localStorage 的测试先取快照，测完还原；收尾清掉测试残留，让站点回到干净初始态。

## 验收标准
- 控制台 0 错误（不含第三方提示）；
- 目标功能与关联功能闭环全通过；
- 原文件已备份，文件编码 UTF-8 无 BOM、换行与原文件一致；
- 修复记录落盘（做了什么/结果/遗留问题）。

## 适用模型
任意具备本机文件读写与浏览器 MCP 能力的编码 Agent（本技能为工具链路级沉淀，与模型绑定弱）。

## 技能补充：从 Codex 会话日志恢复被误删/截断的文件（2026-09-10 实战）

**触发场景**：本地静态站/数据文件被脚本误写坏（截断、覆盖），且项目无 git、无备份。

**步骤**
1. 确认无副本：`git status`；搜索 `_backup_*`；全盘 `Get-ChildItem -Recurse -Filter "<文件名>*"`；确认临时目录无残留。
2. 定位日志：`C:\Users\XTC\.codex\sessions\<YYYY>\<MM>\<DD>\rollout-*.jsonl`，按修改时间取最新的会话文件。
3. 粗筛：逐行读 jsonl，挑出含目标标识（如 `const EXTRA_`）的行并记录行号与体积。
4. 精确提取（关键）：
   - 用 `json.loads` 解析每行，递归遍历出所有字符串叶子（工具调用参数在 `payload/.../arguments`，本身是 JSON 字符串，需二次 `json.loads` 取 `cmd`）；
   - 若文件是「分批长成」的，不要指望一次拿到完整文件——改为**按数组名逐个提取**：对每个 `const X = [` 做括号配平截取，取体积最大/行号最新的版本；
   - 若负载藏在 PowerShell here-string 中，用正则 `@'\n(.*?)\n'@` 抽取，并按内容特征（`transcript:` / `keyPassage:` / `exp:` / `year:`）分类归属。
5. 重组：用磁盘上完好的部分 + 提取负载拼回原文件；**补齐缺失的逗号**。
6. 校验：`node --check` 语法；再用 `new Function(src + '; return {...}')` 做数据层断言（条目数、字段完整性、重复项）。
7. 回归：浏览器重载，逐页跑 DOM 断言 + 控制台查错。

**验收标准**：语法通过 + 各数组条目数与事故前一致 + 浏览器零控制台错误。

**适用模型**：具备命令行与脚本能力的任意模型。

**踩坑提醒**：会话日志里同一数组可能存在多个版本（早期骨架 / 中期补丁 / 后期修正），务必按「行号靠后 + 体积更大 + 内容特征匹配」择优，并用条目数做交叉验证。
