# 技能：视频生产_H3Motion拼贴动画长视频

## 技能名
H3Motion 拼贴动画长视频生产（MiniMax H3 本地 ComfyUI 链路）

## 触发场景
- 习总/客户要"AI 一句话生成拼贴动画长视频"（豆包+minimax 同款玩法）
- 需要 30-60s 的竖屏口播动画：纸艺定格/复古拼贴/情感故事类
- 任何"单模型时长超限 → 需分段无缝拼接"的视频生产

## 前置依赖（首次需习总批准安装）
- 硬件门槛：NVIDIA 3060 8GB 及以上（习总 RTX 5060 Laptop 8GB 满足）；D 盘剩余 ≥30GB；内存 ≥16GB。
- ComfyUI（≥0.30.0，官方原生支持 H3）
- MiniMax H3 权重（开源免费，2B-fast 版；文生/图生/参考生视频三模板）
- 插件：ComfyUI-H3-Motion-Context（GitHub NikoDemon80）+ ComfyUI FIFO

## 步骤（对齐视频官方玩法，落地为团队工作流）
1. 查库：先查本 skill 与《分析_豆包minimax拼贴动画长视频_20260815.md》；复用提示词库拼贴动画条目。
2. 输入：一段口播文案（200-400 字）+ 风格设定（默认纸艺定格 papercraft stop-motion）+ 时长目标（30-60s）。
3. 分镜：把口播按句/按意群切成 N 段（每段 6-7s，H3 单段 15s 上限取 7s 稳区），每段配"画面描述 + 声音/音效"提示词（Minimax 提示词 skill 逻辑：文案反推画面与声音）。
4. 链式生成：每段用 Motion Context 节点 + LoadLatent/SvelLatent 传递前段 latent；ComfyUI FIFO 自动排队（6 段约 12-24 分钟，每段 2-4 分钟）；720P 9:16 竖屏。
5. 拼接：Trim 各段（7s→6s 去首尾冗余）→ ffmpeg 顺序拼接 + 统一音量；仅人声无 BGM（习总规则，若口播需配原生音效则用 H3 自带音频）。
6. QA：抽帧宫格送豆包 vision（画面/文字/风格一致性）+ whisper 转写核对人声；验收：段落衔接无跳变、风格一致、无乱码。
7. 沉淀：每条成片登记使用记录；优质分镜提示词入库提示词库。

## 验收标准
- 成片时长 30-60s、720P 竖屏、段间画面与声音风格一致（Motion Context 生效）。
- 口播完整无缺字，人声清晰无重叠；无 BGM（习总规则）。
- 从口播到成片全自动可一键触发（脚本或 Codex skill）。

## 适用模型/工具
- 视频生成：MiniMax H3（本地 ComfyUI，2B-fast）
- 调度：Codex skill / 豆包桌面任务（二选一）
- 视觉 QA：豆包 ark vision（ep-20260814015916-q97nj）
- 音轨核验：faster-whisper 本地 small
- 拼接：ffmpeg
