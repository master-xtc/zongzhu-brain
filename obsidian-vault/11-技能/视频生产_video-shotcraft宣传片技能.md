# 技能：视频生产 video-shotcraft 宣传片

> 触发场景：网站/产品/项目介绍宣传片、引流短视频、产品演示片
> 适用模型：Codex（总助）+视觉下属验收

## 步骤
1. 工程：复制模板工程（如 template-bim），必做页面尺寸适配：镜头中心坐标按目标页多元素动态计算，绝不写死（实例：BIM网站 2119px vs 模板 10252px，写死 cy 直接对空白）
2. 素材：puppeteer file:// 截取网站关键页图+多页OCR文本，按内容分镜
3. 内容映射：修改 Main/分镜组件/src/aifl/ 下文件，VO/字幕对齐时间轴
4. 特效：速度线飞入/FlashCut琥珀绽放/PaperTitleCard辉光+纹理纸底纹；控制频率，每5s一个高潮点
5. 人声：edge-tts（+20%速率）+BGM（0.12-0.16）
6. 渲染：remotion render --scale=2 --crf=16 --browser-executable=安装版Chrome；ffmpeg转1080p
7. 质检：OCR关键帧无问号+帧亮度数值+音轨包络三合一

## 暗色→亮色改造（新增经验）
- 六处同步：底色/文字/点缀/卡片/弹幕/整页图；经典配方：暖纸白 #F7F4EC底 + 琥珀 #FF7A1A点缀 + 墨黑文字
- 整页图提亮：gamma0.82 + 增益1.12 + 偏移14 三步
- 帧亮度验收：字卡区 200+ 为亮色达标；截图 80-150 可读；整页图若低于80可局部再提或换明亮背景

## 验收标准
- OCR关键帧无 `?` 乱码、无空白镜头；每段分镜内容与文案一一对应
- 人声包络 ≥0.3；语音频段比 ≥0.4佳（低于可降BGM）
- 音轨与画面时长一致（ffprobe验证）

## 常见坑
- headless-shell 无 CJK 字形：渲染/静帧必带安装版 Chrome 路径
- PowerShell 管道写中文文件全为问号：必须 Python \u 转义写入
- JSX 中中文引号用 `{'…'}` 包裹，特殊字符用 \uXXXX

## 备注
- Codex 无视觉时用 OCR+亮度+音轨数据验收（不自欺），美学判断优先派视觉下属
