# 提示词_拼贴动画长视频_H3Motion工作流_v1

## 名称
拼贴动画长视频全自动生产提示词（MiniMax H3 + ComfyUI-H3-Motion-Context）

## 用途
给调度层（豆包任务/Codex skill/总助）一句话下发任务：输入一段口播文案，自动拆分成 6-7s 分段分镜提示词，走 H3 链式生成（Motion Context 保风格一致）+ FIFO 队列，12-24 分钟产出 30-60s 竖屏拼贴动画长视频。

## 适用场景
- 抖音知识/情感/故事类口播动画：拼贴画、纸艺定格、复古素材风
- "口播文案 → 完整成片"全自动链路，零真人出镜、零素材版权风险
- 批量选题量产（如"月球远离地球"科普、"被抛弃的小生命"情感叙事）

## 变量位
- {口播文案}：200-400 字解说稿（本提示词将按意群切段）
- {风格}：默认"纸艺定格动画 papercraft stop-motion"；可换"复古剪报拼贴/暗黑纸艺/童书绘本"
- {目标时长}：默认 36s（6 段 x 6s）；30-60s 范围
- {画幅}：默认 9:16 竖屏 720P

## 正文模板（调度层对模型/脚本的完整任务书，≥百字）
你是一名拼贴动画长视频导演。任务：把下面的口播文案制作成一条{目标时长}秒的竖屏拼贴动画长视频。
1. 分镜：把口播按意群切成 N 段（每段 6-7 秒，N=目标时长/6 向上取整），每段输出三要素——【画面】：主体+动作+场景+构图（复古拼贴/纸艺定格质感）；【声音】：口播对应文字 + 拟音/环境声；【衔接】：与上一段保持的风格元素（人物/场景/色彩延续）。
2. 生成参数：720P、9:16、24fps；用 ComfyUI-H3-Motion-Context 的 Motion Context 节点链式生成，前一段 latent 经 LoadLatent/SvelLatent 传入下一段，确保声音与画面风格一致；提交 ComfyUI FIFO 队列后台运行。
3. 拼接：各段 Trim 去首尾冗余后按序拼接，音量统一；仅保留人声与必要拟音，不加 BGM。
4. 验收：段间无跳变、风格一致、口播完整、无乱码。
【口播文案】：{口播文案}

## 变体
- 科普向：口播 3-4 句一个知识点，画面用太空/微观/自然拼贴素材（例：月球每年远离地球 3.8 厘米）。
- 情感向：第一人称叙事，画面用怀旧物件拼贴（药泡罩、硬币、旧照片）制造"被抛弃的小生命"氛围。
- 播客/漫剧向：可换 MiniMax H3 参考生视频（R2V）锁定人物形象，配合参考音频保音色一致。

## 反例规避
- 禁止每段各自为政：必须传递 latent/风格词，否则段与段画面声音跳变。
- 禁止超过单段 15s：H3 超时质量衰减，稳定区间 6-7s。
- 禁止直接堆 BGM：习总规则视频仅人声，拟音需由 H3 原生生成。
- 禁止口播与画面脱节：每段画面必须由对应文案反推（Minimax skill 逻辑），不是随机生成。

## 验收标准
- 成片时长=目标时长±2s；段间衔接肉眼不可辨、人声口型/情绪连贯。
- 口播逐字完整（whisper 转写比对）；画面文字无乱码（豆包 vision 抽帧核对）。
- 全流程可一键触发：只输入{口播文案}一个变量即出成片。
