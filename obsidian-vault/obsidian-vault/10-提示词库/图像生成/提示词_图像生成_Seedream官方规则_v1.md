# 提示词：图像生成_Seedream官方规则_v1（2026-08-14）

## 名称
Seedream 官方提示词规则与模型选型（吸收自 doubao-seedream-image-skill / 视频学习）

## 用途
豆包 Seedream 出图与图生图的高质量提示词模板，直接配调度网关 `--provider ark --mode image` 使用

## 适用场景
- 文生图（海报/场景/配图/缩略图）
- 图生图编辑（改色/换装/增删元素）
- 多参考图融合（角色/风格/服装组合）
- 图像集/分镜/角色设定图

## 变量位
- {主体} {行为/变化} {环境} {用途/类型} {风格} {色彩} {光影} {构图} {精确文字} {保持不变项}

## 正文模板

### 文生图（单段式，约 300 字内）
```
{主体}，{行为/变化}，位于{环境}，用于{用途/类型}，{风格}风格，{色彩}配色，{光影}，{构图}，标题为“{精确文字}”
```

### 编辑（图生图）
```
保持图一{保持不变项（如人物脸部和姿态）}，将{对象}替换为{新内容}，{操作：增加/删除/修改}，其他部分保持不变
```

### 多参考融合
```
参考图一的{人物形象}，图二的{服装款式}，图三的{线性简约风格}，生成{新场景}，风格/色彩保持一致
```

### 图像集
```
参考图一，生成一组{数量}张同一角色的{表情/动作}设定图：{列出每张}；角色/服装/发型/画风/色彩全程一致
```

## 变体
- 宣传素材：文生图模板 + "16:9 横版宽幅构图" + 深空黑/流光金（团队审美）
- 角色设定：优先正面/四分之三侧脸、稳定光源、清晰五官、服装一致、无文字无水印

## 验收标准
- 主体与提示词一致；编辑时保留项未变；图集角色一致性；无 AI 角标（watermark 默认 false）
