## 变量位
- {风格类}：运动速度感 / 沉浸3D / 叙事滚动 / 极简产品 / 品牌创意 / 高端生活
- {品牌色}：主记忆色（如 荧光绿 #D2FF00 / 保时捷蓝 #1A44EA / IBM蓝 #0F62FE / 暖金 #A89474）
- {场景类型}：网站 / 海报 / 封面 / 配图

## 正文模板

生成{风格类}风格的{场景类型}，遵循以下规格：

1. 色系：{主色}为记忆点，近黑底或纯白底为基底，全页不超过 2 主色 + 1 点缀色；拒绝花哨多色。
2. 字体：展示型定制字体气质（粗衬线高对比 / 窄体几何无衬线 / 细体大字 300 字重），主标题超大号（≥72px），正文克制。
3. 排版：满版大图或大面积留白二选一；一屏一冲击；标题层叠或遮罩式。
4. 氛围：{3-5 个氛围词，如 速度/精确/静谧/未来感/文化感}。
5. 禁忌：不用 emoji、不用廉价渐变、不堆装饰；图文一一对应。

## 变体

1. **运动速度感**（Porsche / Lando Norris / Bruno Simon）：品牌亮色（荧光绿/蓝）+ 近黑底 + 大字号冲击 + 速度感（流线/赛道/光影拖尾）；用于运动、车、电竞赛事。
2. **沉浸3D**（Lusion / Basement / Depth）：近黑或黑白底 + 3D 模型/流体/粒子即主角 + 灯光高光塑形 + 文字极简；用于科技、产品、创意工作室。
3. **叙事滚动**（Locomotive / Uni-Yi / Playground）：深底 + 单强调色 + 细体巨字 + 章节式留白；用于机构、品牌故事、文旅。
4. **极简产品**（Linear / Stripe / Apple）：深色科技或纯白 + 产品大图 + 微光效 + 精密克制；用于 SaaS、数码产品。
5. **品牌创意**（Patrick Heng / Spotify Design）：明快单色（橙/紫）+ 实验排版 + 杂志感；用于个人品牌、设计展示。
6. **高端生活**（Son Daven）：白金双色 + 等宽字体小字标注 + 大图轮播 + 静谧氛围；用于酒店、民宿、生活方式。

## 验收标准
- 色值可落地（给出 HEX）；字体气质可描述（衬线/无衬线/字重）；
- 同一风格下任意两张图可无缝拼贴不出戏；
- 无 emoji、无花哨装饰、无低质占位；
- 使用记录随每次实战回填。
