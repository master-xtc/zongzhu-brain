# 提示词_去AI味蒸馏_网文风格提取与融合_v1

## 一、基本信息
- 名称：去AI味蒸馏·网文风格提取与融合
- 用途：把一部作品的写作风格"蒸馏"成可复用的风格 Skill，并支持多份 Skill 融合、专属优化文档沉淀
- 适用场景：AI 写网文（番茄/起点/晋江等）去 AI 味；模仿对标书风格；建立个人专属写作风格库
- 变量位：{作品名}、{章节范围}、{单次蒸馏字数上限}、{蒸馏遍数}、{Skill 份数}、{融合要求}、{专属优化文档名}
- 来源：抖音 @Openwrite 视频《全网首发去AI味邪修教程》（2026-08-15 学习入库）

## 二、正文模板

### 模板A：风格蒸馏指令（单次）
```
你是资深网文编辑兼写作风格分析师。请对《{作品名}》第{起始章}章至第{结束章}章（共约{字数}字）做"风格蒸馏"：
1. 提取该作品的【文风特征】：句式长短习惯、用词偏好、对话节奏、心理描写密度、环境描写手法、段落节奏（快慢切换点）；
2. 提取【创作习惯】：章节开头切入方式（冲突/日常/悬念）、章末钩子设计、铺垫与回收的节奏、爽点密度与分布；
3. 提取【叙事视角与语感】：视角切换规则、叙述者语气（冷峻/诙谐/庄重）、标点与断句习惯、专有名词命名风格；
4. 输出为一套可直接执行的"风格写作规范"，每条规范配 1 个原文风格例句 + 1 条"反例（AI 味写法）"对照。
约束：只基于给定文本归纳，禁止编造原文没有的特征；单次蒸馏字数不超过 {字数上限} 字，防止幻觉。
```

### 模板B：多份 Skill 融合指令（skill-creator 格式）
```
@skill-creator 将以下九个风格 skill 融合：
1. {Skill名称1}——{一句话核心}
2. {Skill名称2}——{一句话核心}
……（共{Skill份数}份）
融合要求：去重合并重复规则，冲突处以"更贴近{对标作品}语感"的一方为准；输出为一份完整的《{对标作品}风格写作规范》，保留每份 skill 中最有价值的独有细节；结尾附"反AI味自查清单"（10条）。
```

### 模板C：专属优化文档沉淀指令（人机结合进阶）
```
请把以下本次 AI 生成内容的"修改记录"整理成《{专属优化文档名}》：
- 原文片段（AI 味重）：……
- 修改后片段：……
- 修改逻辑：为什么这么改（哪股 AI 味？句式/用词/节奏/情感哪一处不自然）
要求：每条修改提炼成 1 条可复用规则，按"AI味类型（用词/句式/节奏/情感/信息密度）"分类归档；持续追加，最终可整体融入蒸馏技能。
```

## 三、验收标准
- 蒸馏产出：规则可执行、有正例例句 + 反例对照、无编造特征；
- 融合产出：无重复规则、风格统一、含 10 条反 AI 味自查清单；
- 专属文档：每条修改都有"原文/改后/逻辑/规则化"四要素，分类清晰；
- 全流程实测：融合 Skill 生成的内容与对照组相比，AI 味显著下降（肉眼可辨）。

## 四、反例规避（易踩坑）
- 蒸馏样本选错（不是市场验证过的作品）→ 精华变糟粕；
- 单次蒸馏超 10 万字 → 模型幻觉、特征失真；
- 只蒸一遍 → 随机性大、特征不全（至少 3 遍）；
- 9 份 Skill 直接堆叠不融合 → 指令冲突、风格打架；
- 自己分不清 AI 味 → 任何蒸馏都无效，先练"AI 味识别"；
- 想把蒸馏结果当万能 → 它只能贴近喂进去的风格，无法生成你的个人风格。
