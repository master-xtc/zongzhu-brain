# 提示词_建站_动漫能量炸裂颠覆重构_v1.md

## 名称
动漫能量炸裂颠覆重构（健身指挥台 v6 实证版）

## 用途
当习总/客户反馈"太平庸、只加了一点细节、要更炸裂、要颠覆"时，对既有网页做全站级动效重构的调度与实现提示词。以分屏撕裂开场为核心钩子，叠加能量系动效与节奏编排，把"高级感"做成可复制的视觉公式。

## 适用场景
- 既有单页应用（PWA/静态站）需要从"静态/轻动效"升级为"动漫式能量感"；
- 作品集、个人品牌、展示型网站需要"开场即炸裂"的展示力；
- 浅色暖黄/蜂蜜金调性站点（#FAF7F2 底 + #F5B94C 金）或同类品牌色站点。

## 变量位
- `{站点目录}`：网站根目录（如 D:\健身教练\网站\）
- `{版本号}`：本次版本（如 v6.0）
- `{主题色A}`：主底色（默认 #FAF7F2）
- `{主题色B}`：能量金（默认 #F5B94C）
- `{开屏钩子}`：默认"上下分屏撕裂"；可换"卡片碎裂重组/数据风暴/重力塌陷"
- `{核心肌群视觉}`：站内主打部位（胸/肩/背），决定碎片与图示风格

## 正文模板
角色定位：你是动效导演兼前端工程师，为一页式 PWA 做"颠覆级"视觉重构；数据层、localStorage 键、业务逻辑一律不动，只改视觉层与动效层（index.html 结构、main.css、fx.js、app.js 初始化段）。
目标：让首次访问者在 2 秒内被开场钩子击中（分屏撕裂→大标题过冲砸落→粒子冲击波），随后全站保持能量感但不干扰阅读。
受众：习总本人（私用+作品展示）、潜在客户/评委（展示力验收）。
适用场景：桌面+移动端均需成立；移动端只保留撕裂开场+轻量粒子，禁性能杀手。
风格与语气：动漫式能量感——弹性缓动（cubic-bezier 过冲，如 .2,1.45,.3,1）、高饱和撞色、辉光（box-shadow/滤镜 glow）、速度线、能量波纹、画面张力；暖金主色不破。
结构要求：
1. 开场：上下两片面板反向撕裂（各 58vh，clip-path 斜切 + 噪点纹理）+ 金色撕裂能量线横扫 + 大标题从屏幕中心砸落带过冲回弹 + 冲击波扩散 + 方块粒子爆发 + 屏幕微震；sessionStorage 锁，会话仅一次。
2. Hero：斜切大标题（clip-path 斜边）+ 横向无限滚动能量条 marquee + 漂浮能量环/波纹 + 粒子背景。
3. 内容卡：切角卡（clip-path 切角）+ 悬停浮起 + 扫描线周期扫过 + 视口切换金色闪白过渡。
4. 碎片反馈：点击/打卡触发粒子爆发（22 碎片，含三角形 clip-path）、冲击波、速度线、屏幕震动。
5. 桌面滚动：section 竖向撕裂展开（GSAP ScrollTrigger + Lenis 平滑滚动）。
6. 缓存：SW 缓存键带版本号（如 fitness-command-v6）强制用户端更新。
内容要素：所有动效必须带 prefers-reduced-motion 降级；移动端裁剪重粒子；动画统一用 CSS keyframes + 变量驱动时长/缓动。
示例：见健身指挥台线上站（https://fitness-command.netlify.app/）v6 开场与数据卡动效。
反例规避：禁止只加 hover 微光/渐变这类"细节级"改动冒充重构；禁止静态轮播；禁止动效阻塞交互（开场 ≤1.85s）；禁止破坏图文一一对应与数据层。
验收标准：
- 无控制台错误、无横向溢出（桌面 1440 / 移动 390 双验）；
- 开场动画多时间点 getComputedStyle 采样确认真实运行（animationName/transform/opacity）；
- 数据层与 localStorage 键零改动；SW 缓存键版本化；
- 习总真机/无痕窗口验收"开场即炸裂"。
变量位说明：`{开屏钩子}` 可替换为"卡片碎裂重组"（数据卡 22 碎片碎裂→重组为新卡）、"数据风暴"（数字粒子汇聚成标题）等，其余骨架不变。

## 变体
- 变体A 暗黑金旗舰：深空黑 #0A0A0F 底 + 流光金 #C9A96A，撕裂改为"玻璃碎裂"质感；
- 变体B 街头潮流刊：电光紫 #7C3AED 撞色 + 贴纸数据卡（v4.2 已验证）；
- 变体C 柔光健康风：低饱和奶油底 + 柔和能量波（适合女性向健身/健康类客户）。

## 验收标准
交付物必须同时满足：开场钩子 ≤1.85s、全站能量感、移动端不卡顿不溢出、数据层零改动、缓存键版本化；验收以习总/客户在真机无痕窗口的体感为准，总助侧用 DOM 采样验证动画真实执行。
