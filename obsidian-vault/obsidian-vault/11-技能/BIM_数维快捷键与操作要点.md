# 技能沉淀 · BIM_数维快捷键与操作要点

> 领域：BIM 备赛（赛项1 BIM数维设计建模）
> 触发场景：习总在广联达数维建筑设计（GNA）中需要快捷键/操作确认，或做数维 vs CAD/Revit 对比时
> 来源：官方帮助文档（kancloud glodon_garch/gna_s）核实 + 《数维快捷键速查表.md》备赛整理
> 建立日期：2026-08-13

## 核心要点（官方已核实）

1. **删除构件 = Delete 键（Del）**：选中构件后直接按 delete。另两种方式：①助手对话框"删除"工具；②先点删除工具、再选构件，按空格(Space)或回车(Enter)确认选择集。
2. **数维快捷键体系**（比赛用得到的）：墙 Q / 柱 Z / 楼板 LB / 门 MM / 窗 CC / 墙洞 QD / 板洞 BD / 双跑楼梯 LT / 女儿墙 NV / 反檐 FY / 台阶 TJ / 散水 SS / 轴网 ZW / 门窗编号 MC / 房间 FJ / 房间注释 BF / 文字 WZ / 标高标注 BG / 移动 M / 复制 C / 旋转 R / 阵列 AR / 镜像 MI / 偏移 O / 对齐 AL / 测量 DI / 修角 F / 打断 SL / 延伸 TR / 扣减 SU / 墙连接 LJ / 隐藏 EH / 重置隐藏 HR。
3. **易混陷阱**：数维 Z=柱（CAD 的 Z=缩放视图）；数维 C=复制（CAD 的 C=圆）；数维 TR=延伸（CAD 的 TR=修剪）；三维旋转视角=Ctrl+中键（CAD/Revit 都是 Shift+中键）。
4. **比赛禁画**：梁、基础、雨棚、保温层、地下层——对应快捷键（如 LL 梁、CV 车位）比赛用不到，已从快速上手版剔除。
6. **楼层管理 = LCGL / 设置标准层 = BZC**（习总实测：拼音首字母，符合数维键位规律；官方快捷键文档未收录，以软件实测为准）。LCGL 只管设层高，设置标准层是独立命令 BZC。
7. **无字母快捷键的常用功能**：模块、栏杆、坡道、门窗表、模型检查、导出 XML——官方均未分配字母键，走菜单操作（可在系统设置自定义改键）。注意：网传的模块快捷键 MK 不实，勿信。
5. **视图/系统**：缩放=滚轮；平移=按住中键；正交 F8；保存 Ctrl+S；撤销 Ctrl+Z / 重做 Ctrl+Y；每 15 分钟保存一次。

## 步骤（快速上手路径）

1. 先背建模三键：Q 墙 → MM/CC 门窗 → LB 楼板；
2. 再背提速三键：C 复制 / MI 镜像 / AR 阵列；
3. 记住独家视角键：Ctrl+中键 旋转三维；
4. 删除用 Delete，删错立即 Ctrl+Z；
5. 每完成一层 Ctrl+S。

## 验收标准

- 不看表能报出：建模 11 键、编辑主力键、Delete 删除、Ctrl+中键旋转、F8 正交。
- 能说出 3 个"数维 vs CAD 易混点"（Z/C/TR/旋转视角）。
- 能在软件里 5 分钟内完成：建墙→放门窗→铺板→Delete 删除→Ctrl+Z 撤销→Ctrl+S 保存。
