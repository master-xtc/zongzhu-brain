# 技能：可视化双引擎联动与隐藏容器守卫

## 技能名
可视化双引擎联动与隐藏容器守卫（visual_dual_engine_guard）

## 触发场景
- 构建 2D/3D 双视图可视化（SVG + Three.js 等），两视图共享参数；
- 任何基于容器尺寸（clientWidth/clientHeight）的布局（fit/缩放/居中/分块）；
- 容器可能被 display:none 隐藏后再次显示的页面。

## 步骤
1. 布局前守卫：容器不可见（clientWidth < 10）时，不执行尺寸依赖的 fit/apply，只标记 `__pendingFit = true` 后 return。
2. 参数联动统一走事件钩子：3D 重排函数与 2D 重排函数互相补发（如 `__GALAXY_REHEAT` + `__GALAXY_2D_RELAYOUT`），两视图共享同一 GALAXY_PARAMS。
3. 隐藏视图只更新数据不写 DOM 尺寸属性；切回可见时补一次 relayout+fit+tick（自愈）。
4. 初始化幂等：`if (!gInit) initGraph(); else 补渲染();`，防止重复初始化。
5. 验证用 DOM 断言而非肉眼：viewBox 宽高>0、节点数、参数值、事件计数、console 无 error。

## 验收标准
- 隐藏视图期间调参，可见视图的 viewBox/画布不被写坏；
- 切回视图后内容完整、布局适配新参数；
- console 0 error；DOM 断言可复现。

## 适用模型
Codex / Claude / 任意可执行浏览器自动化验证的模型。
