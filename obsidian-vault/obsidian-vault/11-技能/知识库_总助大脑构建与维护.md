# 技能：知识库_总助大脑构建与维护（可视化+对接任意AI）

## 技能名/触发场景
- 触发：习总要求"可视化知识库/把我的记忆做成库/让别的AI接任总助/总助大脑"；或需要把一套分散的 markdown/json 资产整合成可对接任意 AI 的知识库。

## 步骤
1. 查库：扫 团队共享记忆 → memories → 提示词库 → growth(skills/reviews/log) → 项目目录，生成资产索引（collect.py 模式）。
2. 策展：按 身份/规则/能力/知识/项目/员工/工具/红线/记忆/技能/提示词/复盘 十二板块写结构化 JSON；能力按七大域（视频/网页/视觉/文案/自动化/协作/调度）。
3. 生成双格式：knowledge.json（机器可读）+ knowledge.md（单文件激活版，含激活指令、查库清单、对接速查）。
4. 可视化：深空黑 #0A0A0F + 流光金 #C9A96A、SVG 线性图标、原生力导向图谱（400 迭代/8 节点半径）、数据内嵌（file:// 下 fetch 会被 CORS 拦，必须内联）。
5. 对接层：HTTP API（CORS 全开，/api/knowledge、/api/search、/api/activation 等）+ MCP stdio（换行分隔 JSON-RPC：initialize→tools/list→tools/call）。
6. 验证：API 用 Invoke-RestMethod 实测端点；MCP 用管道喂 6 条消息实测；可视化用 playwright 开页查 console + DOM 断言（KPI/节点数/页签切换）。
7. 沉淀：复盘入 growth\reviews\、激活提示词入提示词库\调度指令\、本文档入 skills\；使用说明给习总。

## 验收标准
- 图谱节点数 = JSON 图数据节点数；页签全切通；API 9 端点全通；MCP 握手+7 工具全通；
- knowledge.md 单文件可被任意 AI 独立读取并复述身份/红线；
- 使用说明含三通道对接方法与维护方法（重跑 4 条 python 命令即可刷新）。

## 适用模型
- Codex（总助）全链路可执行；文本模型可读档案激活；部署需 Node 环境。
