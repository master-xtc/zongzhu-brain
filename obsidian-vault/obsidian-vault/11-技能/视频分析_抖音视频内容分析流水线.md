# 视频分析_抖音视频内容分析流水线

## 技能名
抖音视频内容分析流水线

## 触发场景
- 习总或下属提供抖音分享链接并要求分析视频内容
- 需要提取视频口播文案、画面文字、图文一致性核查、元数据统计

## 步骤
1. 解析短链：playwright 打开分享页，取页面 JSON 中视频 ID 与全部元数据（作者/时间/点赞/收藏/评论/分享）
2. 下载：yt-dlp 或 dl 脚本抓 video_{ID}.mp4，ffmpeg 转 audio_{ID}.wav
3. 转写：faster-whisper（transcribe_any.py）→ transcript_{ID}.txt/.json
4. 抽帧：ffmpeg 每 2 秒一帧 → frames_{ID}/frame_XXX.png
5. OCR：rapidocr_onnxruntime 批量 → ocr_frames_{ID}.json
6. 校正：whisper 术语误识别 × OCR 屏幕文字双向印证
7. 整合：8 节分析报告落窗口主目录；复盘/提示词回填团队公共库

## 验收标准
- 报告 8 节齐全；每个画面结论有 OCR 文字证据；无脑补画面描述
- 产物命名规范、全部落窗口主目录；复盘与提示词使用记录已更新

## 适用模型
- 总助 Codex（统筹）+ 视觉下属（可选，OCR 可兜底画面文字）
- 工具链：yt-dlp / ffmpeg / faster-whisper / rapidocr_onnxruntime / playwright
- 2026-08-13 补充：yt-dlp 常报「Fresh cookies needed」；更稳路径 = playwright 渲染分享页后直接取 document.querySelector('video').currentSrc，再用 curl 带 UA + Referer: https://www.douyin.com/ 下载，一次成功
- 视频内出现 GitHub 仓库时，用 GitHub API 复核星标/协议/活跃度，口播数据（如「4万星」）不可直接采信


- 2026-08-14 补充：定位视频中匿名开源项目，repos 搜索未命中时改用 GitHub code search 搜画面里的独特文件名/路径（如 preview-dark.html）一次命中；OCR 零散 token（voltagent）可反推 owner（VoltAgent）；口播 star 数据以 GitHub API 实时值为准并标注时点差异

- 2026-08-14 补充（长视频）：抖音 5 分半长视频常音画分离——video 流（video-hvc1/video-hevc）无音轨，需从页面媒体列表单独抓 audio-und-mp4a 流（m4a）再 ffmpeg 转 wav；抽帧间隔按时长放宽（5 分半用每 10 秒 33 帧）；转写术语误识别率随时长显著上升（如 SKILL→Skill、impeccable→Impactable），须以 OCR 屏幕文字逐条双向校正，不能只信 whisper

- 2026-08-14 补充（抖音音画分离）：douyinvod 媒体 URL 分两条——`media-video-hvc1`（纯视频流，无音轨）与 `media-audio-und-mp4a`（纯音频流）；只下视频流时 ffmpeg 转 wav 会报 "Output file does not contain any stream"。正确流程：分别 curl 两条 URL（带 UA + Referer: https://www.douyin.com/），视频流留作抽帧，音频流 ffmpeg 转 16k 单声道 wav 后再 whisper。
- 2026-08-14 补充（豆包视觉语义核对）：豆包 ark vision（网关 --provider ark --mode vision）可作"不脑补"的画面语义证据，与 OCR 互证；ARK_API_KEY 存用户级环境变量，需进程内 `$env:ARK_API_KEY=[Environment]::GetEnvironmentVariable('ARK_API_KEY','User')` 后调用；单帧 40-140s 波动大，批量核查建议单批 ≤4 帧。

- 2026-08-14 补充（netlog 抓直链·反爬升级）：抖音分享页被 4XX 拦截、detail API 空响应时，用 headless chrome `--log-net-log=xxx --net-log-capture-mode=IncludeSensitive --virtual-time-budget=20000 --dump-dom https://www.douyin.com/video/{id}`，再解析 netlog 里的 douyinvod URL（video 流 + media-audio-und-mp4a 音频流分离下载）；不依赖 playwright 浏览器实例（被占用时依然可用）。
