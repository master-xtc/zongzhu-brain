# 技能：视频生产_Remotion数据可视化动画

## 技能名
Remotion 数据可视化动画（bar chart race / 地图动画 / 形状演化）

## 触发场景
- 需要条形图竞速（bar chart race）、数据排名动画、坐标/地图类动画、形状演化等数据展示视频
- 抖音干货号/工作室案例：数据可视化动画、榜单排名动画、路线路径动画
- 数据以代码/JSON 注入，可批量、可复用（来源：20260814 抖音 Codex+Remotion 全流程视频分析）

## 步骤
1. 查库：reviews/skills/提示词库查同类任务沉淀；数据源先确认（CompaniesMarketCap/腾讯行情/公开统计/自建数据）。
2. 数据准备：数据整理为 JSON（对象名/数值/时间序列），**必须标注数据源与访问日期**（专业感细节）。
3. 工程搭建：拷贝 video-shotcraft/宣传片 Remotion 模板（npm i 就位 node_modules）。
4. bar chart race 实现要点（2026-08-14 美股+A股案例实测）：
   - 每帧根据时间插值市值/数值，按数值排序生成条形；入场用 easeOut 生长（enter=(rel-rank*2)/10），排名轮换自然。
   - 结构：标题卡（2s）→ 图表段（每年 36 帧=1.2s，逐段 easeInOut 插值）→ 资料卡（每张 3s，可加 3 张）→ 结尾卡（5s）；总帧数 = 60 + 年数*36 + 90*资料卡数 + 150。
   - 布局：左公司名区 LABEL_W=300 + 条形区 MAX_BAR_W=1080 + 右数值区；行高 = 图表高/公司数（12 家≈59px，14 家≈50px，字号相应 27/23）。
   - 年份大字：**必须与数据段年份同步**（直接取 curYear），禁止 Math.round(浮点年份) 造成年中提前滚动、大小年份不一致。
   - 长条形数值标签：条形宽度 >60% 最大宽时数值内嵌白字（左偏移、白字+阴影），否则外置深色；避免与右上角年份大字重叠；年份大字 96px 为宜。
   - 数据单位校验：渲染前用已知锚点抽查（美股 Apple 2024≈$3.7T；A股 2007 中石油 4.75 万亿>工行 2.90 万亿、2015 工行 1.63 万亿第一、2021 茅台 2.56 万亿>宁德 1.41 万亿、2026 工行 2.69 万亿>中移动 2.12 万亿），防抓取单位 10 倍错误。
   - 公司当年无数据则跳过（未上市公司自然出现），标题"Top 14"在早年会少于 14 家，属预期。
   - 底部渐变进度条 + 数据源与年份区间标注。
   - 中文用 NotoSerifSC-VF/NotoSansSC-VF，绝对定位避免 inset 冲突。
   - 事件标注（EVENTS）：A股/美股各自史实；相邻年份事件用严格 `curYear === e.year` 匹配避免互相遮蔽（2007 与 2008 事件都要显示时，不能用 year+1 窗口）。
   - 深色主题（2026-08-14 A股 v3 实测）：深空黑 #0A0A0F 底 + 流光金 #C9A96A 点缀，条形用低饱和多色系，A股红涨绿跌（RED=涨 #E0443A / GREEN=跌 #2FA17C）；文字用暖白/浅金，与浅色美股版鲜明区分，每份视频各有特色。
   - 上证指数年度K线尾注（2026-08-14 A股 v3 实测）：每年初在图表右上/左下淡入"上证指数年度K线"小卡——开盘/收盘/最高/最低 + 年度涨跌幅%（红涨绿跌）；颜色判定 `up = close >= open`，涨跌幅 `(close-prevClose)/prevClose*100`；数据用腾讯 web.ifzq.gtimg.cn 月线（前复权）+ prevClose=上年收盘；K线画法：bodyH=abs(close-open)/range*H、bodyTop=(high-max(open,close))/range*H、影线用 high-low。
5. 数据源坑（2026-08-14 A股实测）：
   - A股总市值口径：腾讯行情 qt.gtimg.cn 实时 f[45]总市值/f[3]现价 得最新总股本，× web.ifzq.gtimg.cn 月线前复权价 = 各年末市值（百万元人民币）。
   - **qfq 损坏检测**：前复权/不复权比值最小值 <0.15 的股票（中石油、中信证券、宁德时代、比亚迪、中国移动）改用手动不复权数据，否则早期价格趋近 0/负值。
   - 东财 push2 接口常被代理拦截不可用；akshare 也可能失败，腾讯行情最稳。
   - 缺失年份（未上市/停牌）允许缺省，组件 getCap 返回 null 跳过。
6. 地图动画（可选）：高德开放平台（lbs.amap.com）注册个人开发者 → 创建应用 → 新增 Key（免费）；把 Key+安全密钥交给 AI 取地图数据/坐标；用于路径、站点、区域动效。习总 Key 已存用户级环境变量 GAODE_API_KEY。
7. 配音（解说 VO，2026-08-14 起）：
   - **习总硬规则（2026-08-14 起）：视频一律仅人声、不要 BGM；音效默认也不用（需批准）。**
   - edge-tts（免费）男声新闻腔：`zh-CN-YunyangNeural`，rate `-6%`；脚本 gen_vo.py 批量生成 mp3。
   - **VO 不重叠硬性标准**：每段时长必须 ≤ 到下一段起点的时间窗；生成后用 ffprobe 测时长逐个核对（相邻段间隔至少留 0.1s 余量）。
   - 解说文案：短句、年份用中文数字（二零零八年），单句控制在目标窗内。
   - 音轨验证：ffmpeg 抽音频 → faster-whisper（本地 small 模型）转写带时间戳，逐段核对内容顺序且无双声叠加。
8. 渲染：npx remotion render src/index.ts <CompositionId> out/xxx.mp4 --crf=14（h264 高码率；40s/13MB 约 1 分钟内）。
9. QA 复核：ffmpeg 抽帧（-vf "select=eq(n,帧号)" -frames:v 1，多帧拼 xstack 宫格一次送审）+ 豆包 vision 逐格核对（数值锚点/年份一致性/排序/重叠/截断/乱码/黑边），提示词见提示词库《提示词_图表动画视觉核对_豆包vision_v1》；K线/涨跌颜色结论必须与数据交叉验证（close>=open 红涨、close<open 绿跌），存疑时放大截图二次复核。

## 验收标准
- 数据逐项正确（与源数据一致，且过已知锚点校验）、排名轮换平滑、无乱码黑边；字幕逐字正确；数据源标注清晰。
- 音频：**仅人声无 BGM/音效**；**相邻 VO 无重叠**（ffprobe 测时长 + whisper 转写双重验证）；无 BGM 验证 = ffmpeg volumedetect 检查人声间隙 RMS=0 纯静音。
- 成片可复用：数据 JSON 与组件解耦，换数据即换视频。
- 每份视频有自己的风格特色（美股=浅色科技质感；A股=深空黑+流光金+K线红绿），禁止千篇一律。
